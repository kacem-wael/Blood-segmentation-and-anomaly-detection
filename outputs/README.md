# Pipeline outputs

Generated by `scripts/export_steps.py` (`make outputs`); do not edit by hand.
Folder `NN-name` holds the result of steps 1..NN applied in order to each image.
Masks are white = foreground; float channels are stretched to 0-255 for display.

| # | folder | step |
|---|--------|------|
| 1 | `01-original` | input RGB image |
| 2 | `02-green_channel` | G channel of RGB (hemoglobin absorbs green: cells dark) |
| 3 | `03-median_filter` | median filter, disk radius preprocessing.median_r px |
| 4 | `04-scale_coarse_mask` | scale bootstrap: Otsu on the median-filtered green channel + fill_holes |
| 5 | `05-scale_granulometry` | pattern spectrum of the coarse mask (openings by disks) -> RBC radius r |
| 6 | `06-background_closing` | grayscale closing by a disk of tophat_r x r: background estimate |
| 7 | `07-relative_tophat` | (closing - image) / closing: cells bright, flat background |
| 8 | `08-cells_normalized` | percentile contrast stretch of the top-hat to [0, 1] |
| 9 | `09-cells_otsu` | Otsu threshold of the cells channel: raw cell mask |
| 10 | `10-purple_lab_b` | -b* of CIE Lab: purple stain (nuclei, platelets) bright |
| 11 | `11-purple_median_normalized` | median filter + contrast stretch of -b* |
| 12 | `12-purple_otsu` | Otsu threshold of the purple channel: raw purple mask |
| 13 | `13-purple_opening` | purple mask: opening by a disk of purple_open_r x r |
| 14 | `14-purple_closing` | purple mask: closing by a disk of purple_close_r x r |
| 15 | `15-purple_remove_small_objects` | purple mask: remove objects < purple_min_area x pi r^2 -> PURPLE MASK |
| 16 | `16-cells_union_purple` | raw cell mask OR purple mask (a nucleus is a cell even with weak green contrast) |
| 17 | `17-gap_closing` | closing by a disk of gap_close_r x r: seals open RBC rims (C shapes) |
| 18 | `18-hole_fill` | fill small, round, convex holes (RBC pale centres), not gaps between cells |
| 19 | `19-opening` | opening by a disk of open_r x r: noise, thin bridges |

| 24 | `24-wbc_nuclei` | nuclei = groups >= wbc.nucleus_min_area x pi r^2 (one colour per WBC) |

| 26 | `26-wbc_markers` | watershed markers: nucleus (grown), background (dark), RBC competitors (light) |

| 28 | `28-platelet_candidates` | purple components outside the WBCs, grouped by platelets.group_r x r |
| 29 | `29-platelet_enclosure` | candidates kept (green), enclosed in a cell (red), wrong size (grey) |
| 30 | `30-platelets` | final platelets (stained cores) |
| 31 | `31-rbc_mask` | cell mask - WBCs - dilated platelets, opened: input of the RBC watershed |
| 32 | `32-distance_transform` | Euclidean distance to the background, Gaussian-smoothed |
| 33 | `33-ultimate_erosion` | regional maxima of the distance (ultimate erosion), for comparison |
| 34 | `34-hmaxima_markers` | h-maxima of the distance (dynamic >= separation.h x r): one marker per RBC |
| 35 | `35-skiz` | geodesic SKIZ of the markers inside the RBC mask (zones of influence, bonus) |
| 36 | `36-watershed_rbc` | watershed of -distance from the markers inside the RBC mask (one colour per RBC) |
| 37 | `37-label_map` | all objects: WBCs, platelets, RBCs (precedence WBC > platelet > RBC) |
| 38 | `38-label_contours` | morphological gradient of the label map: contours incl. watershed lines |
| 39 | `39-classification` | final classes: RBC red, WBC blue, platelet green, with object ids |
| 40 | `40-anomalies` | flags: anomaly (yellow fill), clump (orange), border / not eligible (grey) |
